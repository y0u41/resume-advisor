# 产品需求文档（PRO）

> 项目：简历参谋（resume-evaluator）
> 版本：v1.0 ｜ 整理日期：2026-09-11

## 1. 产品定位

**一句话**：贴简历 + 说岗位 → 评分、挑刺、改法、岗位匹配。

面向求职者（尤其应届生）的求职全流程工具，覆盖「没简历 → 评估 → 多岗对比 → 改简历 → 面试准备」的完整闭环。

## 2. 目标用户

- **主力**：应届生 / 在校生（应届生模式）
- **次主力**：1–3 年职场新人（转岗 / 跳槽）
- **长尾**：泛求职者（自查简历、面试准备、生成简历）

## 4. 功能详述

### 4.1 简历评估（核心）

- **输入**：简历全文 + 应聘岗位（必填）；岗位 JD（选填，填了更准）。
- **输出**：严格固定 9 节的报告——
  1. **总分**：十分制（9–10 可直投；7–8 小改；4–6 明显短板；1–3 不匹配/质量差），理由须引用简历原话。
  2. **一句话结论**。
  3. **岗位匹配对照**（最重要）：逐条列出 JD 要求，每行 `匹配标记 | 要求原文 | 简历对应情况`；标记仅 ✅/⚠️/❌；对应情况须引用原句，未写则"简历未提及"。
  4. **三大优点**：引用原句。
  5. **问题清单**：指出具体哪句话有问题 + 为什么。
  6. **逐条改法**：每条问题给"改之前 → 改之后"对照。
  7. **AI 修改建议**：3–5 条按优先级排序的修改动作 + 一段"优化后示范"（禁止编造）。
  8. **关键词补齐**：对照 JD 列出缺失关键词，顿号分隔，不加编号/解释。
  9. **可继续增强的方向**：技能 / 经历 / 加分项三类可执行建议。
- **交互**：流式输出，实时显示；支持修改简历 / 岗位 / JD 后重新评估。
- **约束**：缺简历先要简历，缺岗位先问岗位，两者齐全才开始评估。

### 4.2 岗位匹配对照

- 逐条对照 JD，✅ / ⚠️ / ❌ 标注，前端渲染为带进度条的匹配度（`ok + partial×0.5`）。

### 4.3 多种录入方式

- **直接粘贴**文本。
- **上传文件**：PDF / DOCX / DOC / TXT / MD，拖拽上传，单文件 ≤ 10MB。
- **图片 / 扫描版**：jpg / jpeg / png / webp / bmp / gif 直接 OCR；图片型 PDF 自动渲染后 OCR（最多 5 页）。
- **粘贴岗位链接**：抓取网页正文 → LLM 智能提取岗位重点（职责、要求、薪资等），过滤导航/广告/推荐噪声。

### 4.4 应届生模式

- 开关式。开启后：不因无工作经历扣分；"经验年限"类要求按"是否具备相应能力/项目"判断；改法与增强方向贴合应届生可补充的内容。

### 4.5 继续追问

- 基于简历 + JD + 此前报告，就具体段落反复打磨（重写自我评价、项目改 STAR 等），只输出改好的那段。

### 4.6 多岗位对比

- 一份简历同时对比多个 JD，按评分排序给出匹配度与结论。

### 4.7 模拟面试

- 根据简历 + JD 生成：面试概览、1 分钟自我介绍、专业/技术题、项目深挖题、行为面试题、反问环节、面试前提醒。可下载。

### 4.8 岗位方向推荐

- 不知道投什么时，根据简历推荐 3–5 个岗位方向（为什么适合 + 需补强 + 关键词）+ 求职建议。

### 4.9 简历模板生成器

- 填内容 → 实时预览 → 下载 → 可直接去评估。
- 两套视觉模板（单栏经典 / 左右分栏）× 三种内容顺序；支持插入证件照；**多版本管理**（按岗位保存/切换/删除）；草稿自动保存。

### 4.10 多格式下载

- 报告、简历、面试准备、方向推荐均支持 PDF / Word / TXT / Markdown。

### 4.11 多用户与额度

- 邮箱注册 / 登录；数据按 `user_id` 严格隔离；每人每日评估次数上限（默认 30）。
- 管理员用**用户名**登录，拥有用户管理页（查看用户、当日用量）。

### 4.12 多模型

- 内置 DeepSeek 与智谱 GLM，界面按提供商分组选择具体模型（含免费 / 旗舰），选择记忆；`LLM_PROVIDER` 仅作默认值。

### 4.13 体验与工程

- 并发队列（超出排队）、结果缓存去重、失败自动重试、请求日志。
- PWA（可"添加到主屏幕"）、深色模式、全局 Toast、骨架屏、首次引导、移动端适配。
- **后台任务**：评估 / 多岗对比 / 模拟面试 / 岗位推荐在**应用级后台运行**，切换页面不中断、可**多任务并行**；右下角悬浮任务栏可随时查看。

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 安全 | 除注册/登录外全部鉴权；密钥不入库；链接抓取防 SSRF；接口限流 |
| 隐私 | 独立隐私政策页；`data/` 不入版本库；数据按用户隔离 |
| 性能 | 评估流式输出；相同输入走缓存；并发上限 5、队列 50 |
| 可用性 | 失败自动重试；流式停滞超时后回退非流式 |
| 成本 | 默认免费模型兜底；缓存减少重复调用 |

## 6. 范围之外（已知限制）

- 动态渲染（SPA）或需登录的招聘网页，服务器拿不到正文，会回退原始文本或提示手动复制。
- PDF 导出为图片式渲染（文字不可选中），如需可编辑请下载 Word。
- 报告结构化依赖模型遵循固定格式，偏差时前端降级为纯文本展示。
- "同一个人"以简历首个非空行（通常为姓名）识别，重名会合并。
- 国内服务器 + 未备案域名只能用 `IP:端口` 访问，无 HTTPS。

## 8. 近期新增（2026-09-11 / 09-12）

- **客观评分（算法）**：确定性引擎输出可复现的匹配度与四维评分，与 AI 报告**并存、相互印证**。
- **结构化简历 Schema**：前后端共用的简历契约（Zod），写严读宽。
- **账号注销**：7 天冷静期、可撤销，到期物理删除账号与全部数据。
- **下载历史**：回看导出记录（报告 / 简历）。
- **乐观并发**：编辑保存冲突返回 409 并提示刷新，避免覆盖。
- **后台任务**：长任务跨页面后台运行、可并行。
- **健壮性修复**：PDF 按坐标重建阅读顺序（修正设计型简历乱序/内容错位）；默认关闭推理模型思考链（避免正文为空）。
- **游客免注册试用**：未登录可按 IP 试用 1 次（结果打码预览），注册后解锁完整报告 / 下载 / 历史。
