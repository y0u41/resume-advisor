# 历史记录

> 按人分组的评估记录、下载记录，以及账号与隐私（注销）。

## 概述

集中管理个人数据：回看历次评估、查看下载记录、注销账号。数据按用户严格隔离。

## 入口

- 路由：`/history`（`src/pages/History.tsx`）

## 功能

### 1. 评估记录
- 按「同一个人」分组（以简历首个非空行识别），同一人**最多保留 12 次**提交，超出自动删除最旧。
- 每条可进入结果页（`/result/:id`）查看，或删除单条。

### 2. 下载记录
- 展示最近 100 条导出记录（报告 / 简历、格式、时间）。

### 3. 账号与隐私
- 自助**注销账号**：7 天冷静期，期间可撤销；到期由定时任务物理删除账号与全部数据。
- 冷静期内页面显示横幅与「撤销注销」。

## 后端

| 接口 | 说明 |
|------|------|
| `GET /api/evaluations` | 评估列表（含当日用量） |
| `GET /api/evaluations/:id` | 单条详情（含 `objective`） |
| `PUT /api/evaluations/:id` | 修改（乐观并发 `revision`，冲突返回 409） |
| `DELETE /api/evaluations/:id` | 删除单条 |
| `GET/POST /api/downloads` | 下载记录读取 / 记录 |
| `GET /api/account/status` | 注销状态 |
| `POST /api/account/delete` | 申请注销（进入冷静期） |
| `POST /api/account/cancel-delete` | 撤销注销 |

关键实现：`server/routes/evaluate.js`（历史 CRUD）、`server/routes/downloads.js`、`server/routes/account.js`、`server/jobs/purge.js`（到期清理）。

## 数据

- 表 `evaluations`（`user_id` 隔离、`person_key` 分组、`revision` 乐观并发）
- 表 `downloads`、表 `users`（`deleted_at` / `purge_after`）

## 注意事项

- 「同一个人」按姓名识别，重名会合并。
- 修改记录采用乐观并发：客户端带 `revision`，不匹配返回 `409` 并给出最新 `currentRevision`。
- 注销后不可恢复；数据清理在服务启动时及每 6 小时执行一次。
