# 评估简历

> 核心功能：贴简历 + 说岗位 → 评分、逐条对照 JD、改法与增强方向。

## 概述

输入简历全文与目标岗位（JD 选填），生成一份**固定 9 节**的结构化报告，并同时给出**算法客观分**与**AI 主观报告**，两者相互印证。

## 入口

- 路由：`/`（`src/pages/Home.tsx`）
- 运行中页面：`/result/task/:taskId`（`src/pages/TaskRunner.tsx`）
- 结果页：`/result/:id`（`src/pages/Result.tsx`）

## 使用流程

1. 粘贴简历全文，或上传文件（PDF / Word / TXT / **图片 / 扫描版 PDF 自动 OCR**）
2. 填写应聘岗位；可选填 JD（可粘贴链接**智能抓取**岗位重点）
3. 可选：勾选「应届生模式」、选择模型（DeepSeek / 智谱 GLM）
4. 点击「开始评估」→ 任务进入**后台运行**（可切换页面）
5. 完成后自动跳转结果页；可编辑简历/JD 后「再次评估」，或「继续追问」

## 输入 / 输出

- 输入：`resume`（≤40000 字）、`jobTitle`（≤200 字）、`jobDescription`（≤40000 字）、`jobUrl`、`candidateType`、`provider`/`model`
- 输出：
  - `report`：9 节报告 —— 总分 / 一句话结论 / 岗位匹配对照 / 三大优点 / 问题清单 / 逐条改法 / AI 修改建议 / 关键词补齐 / 可继续增强的方向
  - `objective`：确定性客观分（总分 /100、关键词匹配度、四维评分、命中与缺失关键词、建议）
  - `id`、`score`、`revision`

## 后端

| 接口 | 说明 |
|------|------|
| `POST /api/evaluate?stream=true` | 评估（SSE 流式；失败自动回退非流式） |
| `POST /api/followup` | 继续追问（SSE） |
| `GET /api/evaluations/:id` | 读取单条记录（含 `objective`） |
| `POST /api/parse-file` | 文件解析（含图片 / 扫描版 OCR） |
| `POST /api/fetch-url` | 岗位链接抓取 + 智能提取 |
| `GET /api/models` | 可选模型 |
| `POST /api/resume/validate` | 结构化简历校验 |

关键实现：`server/routes/evaluate.js`、`server/llm/llm.js`、`server/llm/prompt.js`（`SYSTEM_PROMPT`）、`server/scoring/`、`server/core/store.js`。

## 数据

- 表 `evaluations`：`resume / job_title / job_description / score / report / objective_json / revision / person_key / cache_key / candidate_type`
- 缓存：相同输入命中 `cache_key` 直接返回（`CACHE_TTL_HOURS`）
- 额度：每人每日 `DAILY_LIMIT`

## 注意事项

- 报告结构化依赖模型遵循固定格式，偏差时前端降级为纯文本展示。
- 图片型 PDF 提取文字 <20 字时判定为扫描版，走视觉模型 OCR（最多 5 页）。
- 结果「同一个人」按简历首个非空行识别，重名会合并。
