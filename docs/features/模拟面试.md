# 模拟面试

> 根据简历 + 目标岗位，生成面试题、回答思路与自我介绍。

## 概述

基于简历与岗位（JD 选填）生成一份面试准备材料，覆盖面试官真正会考的点，并给出可直接照说的自我介绍。

## 入口

- 路由：`/interview`（`src/pages/Interview.tsx`）

## 使用流程

1. 粘贴简历全文、填写应聘岗位、可选填 JD、勾选应届生、选择模型
2. 点击「生成面试准备」→ 进入**后台运行**
3. 完成后展示内容，可导出 PDF / Word / TXT / Markdown

## 输出结构（固定顺序）

- 【面试概览】重点考察什么（3~4 条）
- 【自我介绍】1 分钟要点
- 【专业 / 技术题】逐题「问题 + 思路」
- 【项目深挖题】针对简历项目
- 【行为面试题】
- 【反问环节】建议向面试官提的问题
- 【面试前提醒】临场注意事项

## 后端

| 接口 | 说明 |
|------|------|
| `POST /api/interview` | SSE 流式生成 |

关键实现：`server/llm/llm.js` 的 `interviewStream`、`server/llm/prompt.js` 的 `INTERVIEW_SYSTEM_PROMPT` / `buildInterviewPrompt`。

## 前端

- 任务：`useTasks().startInterview(payload, title)`
- 页面从 `latestOf("interview")` 读取文本；下载用 `src/lib/report/download.ts` 的 `downloadText`

## 注意事项

- 内容基于简历真实经历，禁止编造（提示词约束）。
- 属于长耗时任务，支持后台运行与切换页面。
