# 岗位推荐

> 不知道该投什么？根据简历推荐适合你的岗位方向。

## 概述

仅凭一份简历，推荐 3~5 个适合的岗位方向，给出「为什么适合（引用简历证据）」「需要补强什么」「关键词」，以及整体求职策略。

## 入口

- 路由：`/directions`（`src/pages/Directions.tsx`）

## 使用流程

1. 粘贴简历全文、勾选应届生、选择模型
2. 点击「推荐岗位方向」→ 进入**后台运行**
3. 完成后展示推荐结果，可导出多格式文件

## 输出结构（固定顺序）

- 【最推荐方向】一个方向 + 一句话理由
- 【推荐方向清单】逐个方向：方向 / 为什么适合（引用证据）/ 需要补强 / 关键词
- 【求职建议】2~3 条策略

## 后端

| 接口 | 说明 |
|------|------|
| `POST /api/directions` | SSE 流式生成 |

关键实现：`server/llm.js` 的 `directionsStream`、`server/prompt.js` 的 `DIRECTIONS_SYSTEM_PROMPT` / `buildDirectionsPrompt`。

## 前端

- 任务：`useTasks().startDirections(payload, title)`
- 页面从 `latestOf("directions")` 读取文本；下载用 `downloadText`

## 注意事项

- 只基于简历真实出现的信息推荐，不凭空假设（提示词约束）。
- 属于长耗时任务，支持后台运行与切换页面。
- 输出中的「关键词」可用于评估页的「关键词补齐」参考。
