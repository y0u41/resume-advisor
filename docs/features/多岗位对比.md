# 多岗位对比

> 一份简历同时对比多个岗位（2~4 个），看看哪个更匹配、更值得投。

## 概述

对同一份简历并行评估多个目标岗位，输出按评分排序的对比表（评分 / 匹配度 / 一句话结论），并可直接查看每个岗位的完整报告。

## 入口

- 路由：`/compare`（`src/pages/Compare.tsx`）

## 使用流程

1. 粘贴简历全文，勾选应届生模式、选择模型
2. 填写 2~4 个岗位（岗位名称必填，JD 选填，可增删）
3. 点击「开始对比」→ 进入**后台运行**，实时显示「正在评估 i/n：岗位名」
4. 完成后展示对比表，点「查看报告」跳转该岗位的完整评估

## 输入 / 输出

- 输入：`resume`、`jobs: [{ title, jd }]`（2~4 个）、`provider`/`model`、`candidateType`
- 输出：`results: [{ id, title, score, matchRate, conclusion }]`（按评分排序）

## 后端

| 接口 | 说明 |
|------|------|
| `POST /api/compare` | 逐个岗位评估，SSE 流式下发进度与结果 |

关键实现：`server/routes/evaluate.js` 的 `/compare`（内部复用单岗评估逻辑并逐条落库）。

## 前端

- 任务：`useTasks().startCompare(payload, title)`（后台运行）
- 页面从 `latestOf("compare")` 读取进度与结果，切换页面后回来仍可见

## 注意事项

- 每个岗位都会生成一条独立的评估记录（可在历史中查看）。
- 至少 2 个、最多 4 个岗位。
- 对比表「匹配度」为**算法客观分口径**（关键词优先由 LLM 从 JD 抽取），与结果页一致；记录同样落 `objective_json`。
- 「评分」为 LLM 十分制。
