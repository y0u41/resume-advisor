# 简历模板

> 填内容 → 实时预览 → 多版本管理 → 导出 PDF / Word / TXT / Markdown → 可直接去评估。

## 概述

面向不会排版 / 没有简历的求职者：按模块填写内容，自动套用专业模板生成简历，支持多版本保存与多格式导出。

## 入口

- 路由：`/builder`（`src/pages/Builder.tsx`）

## 使用流程

1. 填写基本信息（姓名/手机/邮箱/城市/求职意向）与各模块（教育、经历、项目、校园、技能、自我评价）
2. 选择**视觉模板**（单栏经典 / 左右分栏）与**内容顺序**（经典 / 项目优先 / 应届生推荐）
3. 可选插入证件照；实时预览
4. 可保存为**多个版本**（按岗位命名，切换 / 删除）
5. 导出 PDF / Word / TXT / Markdown，或「去评估」直接带内容进入评估

## 输入 / 输出

- 输入：`ResumeData`（扁平字段，见 `src/lib/resume/resumeTemplate.ts`）
- 输出：排版 HTML（预览与 PDF 共用同一渲染器）+ 纯文本（用于评估）+ 多格式文件

## 前端文件

| 文件 | 作用 |
|------|------|
| `src/pages/Builder.tsx` | 页面与表单 |
| `src/lib/resume/resumeTemplate.ts` | `ResumeData`、`resumeToHtml`（排版）、`buildResume`（转文本） |
| `src/lib/resume/resumeSchema.ts` | 扁平表单 ↔ 结构化简历 的转换与校验 |
| `src/lib/report/download.ts` | `downloadResume` 多格式导出 |

## 数据

- 草稿与多版本存于浏览器 `localStorage`（`Draft` / `Version`），**不落库**。
- 导出的简历会通过 `POST /api/downloads` 记录一条下载历史（见「历史记录」）。

## 注意事项

- 导出 PDF 为图片式渲染（文字不可选中）；如需可编辑请导出 Word。
- 「去评估」前会做结构化校验，缺姓名等必填项会拦截。
- 结构化简历的权威定义在 `shared/resumeSchema.js`（前后端共用）。
